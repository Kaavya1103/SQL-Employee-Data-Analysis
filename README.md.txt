# Employee Data Analysis Using SQL

## Project Overview
This project focuses on analysing employee data using SQL and MySQL. It explores employee details, department information, salary patterns, and department-wise statistics.

## Project Objectives
- Retrieve and analyse employee records.
- Filter and sort employee data.
- Calculate salary statistics.
- Analyse department-wise employee information.
- Identify employees earning above average salaries.
- Practise SQL joins, subqueries, CTEs, and window functions.
- Check data quality and data integrity.

## Tools and Technologies
- MySQL
- MySQL Workbench
- SQL

## Database Structure

### Employees Table
Contains employee ID, employee name, department, salary, hire date, city, department ID, and manager ID.

### Departments Table
Contains department ID and department name.

## SQL Concepts Covered
1. Database and Table Creation
2. Insert Data
3. Basic SELECT Queries
4. Filtering and Sorting
5. Aggregate Functions
6. GROUP BY and HAVING
7. Joins
8. Subqueries and CTEs
9. CASE Statements
10. Window Functions
11. String and Date Functions
12. Constraints and Data Integrity

## Key Analysis
- Total number of employees
- Total and average salary
- Highest and lowest salary
- Department-wise employee count
- Department-wise average salary
- Employees earning above the overall average
- Employee ranking based on salary
- Data quality checks
